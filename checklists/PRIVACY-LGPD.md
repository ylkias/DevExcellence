# Privacidade e proteção de dados

Esta lista orienta controles técnicos. A determinação de base legal, papéis de controlador/operador, prazos legais e interpretação jurídica deve ser validada pelos responsáveis de privacidade/jurídico da organização.

- [ ] Dados pessoais e dados pessoais sensíveis são identificados e classificados.
- [ ] A finalidade e a necessidade de cada coleta são documentadas pelo responsável do produto.
- [ ] A aplicação coleta e compartilha somente os dados necessários para a finalidade definida.
- [ ] Base legal, transparência, consentimento quando aplicável e direitos dos titulares possuem fluxo definido pelos responsáveis.
- [ ] Acesso a dados pessoais segue menor privilégio e segregação por usuário/tenant.
- [ ] Dados sensíveis são protegidos em trânsito, em repouso e em backups conforme o risco.
- [ ] Logs, traces, analytics, erros e ferramentas de suporte não expõem dados pessoais desnecessariamente.
- [ ] Retenção, descarte, anonimização e pseudonimização possuem regras implementadas e testáveis.
- [ ] Exportação, correção e exclusão de dados possuem autorização, auditoria e tratamento de dependências.
- [ ] Ambientes não produtivos usam dados sintéticos ou devidamente anonimizados.
- [ ] Integrações e subprocessadores recebem somente os dados necessários e são inventariados.
- [ ] Incidentes envolvendo dados possuem trilha técnica e procedimento de resposta definido.
- [ ] Relatórios da DevExcellence são sanitizados antes de compartilhamento externo.
- [ ] Testes verificam isolamento, exposição acidental, retenção e exclusão.

## Critério de aceite

A aplicação demonstra controles técnicos coerentes com as regras de privacidade definidas pela organização. A skill não declara conformidade jurídica apenas pela presença destes controles.
